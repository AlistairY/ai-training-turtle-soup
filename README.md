# Soup Lab · AI 训练海龟汤

通过训练曲线与 observable 寻找故障，判断模型 setup 应该调高还是调低，让训练恢复正常。

[在线试玩](https://alistairy.github.io/ai-training-turtle-soup/) · [直接体验分层调查](https://alistairy.github.io/ai-training-turtle-soup/?case=08)

- 10 道题，26 组真实训练结果，支持标准与挑战模式。
- 每题 3 点生命；首次查看无关观测扣 1 点，重复查看不重复扣除。
- 每题共享 1 次解读机会，已解锁解读可以免费回看。
- 第 04、07、08 题支持分层调查：查看相关前置观测后，才展示对应的深层检查。合理的排除证据计为有效。
- 切题保留本页内的进度；刷新会重置，重新开始只重置当前题。

## 本地运行

下载 `index.html` 后直接用浏览器打开即可。样式、脚本和训练数据均内嵌，不需要安装依赖或运行模型。

## 部署

此仓库为可直接运行的静态发布版，GitHub Pages 从 `main` 分支根目录发布。更新 `index.html` 并推送后，Pages 会重新部署。

图表来自预先完成的 NumPy MLP 实验。游戏根据正确的调整方向选择对应实验结果，不会在浏览器中重新训练。新增题各使用一个固定随机种子，是教学案例；修复后仍可能存在波动。
