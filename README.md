# Soup Lab · AI 训练海龟汤

[在线试玩](https://alistairy.github.io/ai-training-turtle-soup/) · [体验梯度传递关卡](https://alistairy.github.io/ai-training-turtle-soup/?case=08)

从真实的训练曲线和观测寻找故障，判断模型设置应该调高还是调低。

## 从新手村出发

30 道题分为 5 个大关，每关 6 题，Easy / Medium / Hard 各 2 题：

1. **初曦星系（新手村）**：最初两题仅一个 observable 和一个错误 setup，逐步建立读图直觉。
2. **赤帆星系**：单步进展、反弹、训练时间与组合限制。
3. **千棱星系**：拟合形状、模型容量、有效活动与练习机会。
4. **幽鸣星系**：裁剪、饱和、梯度到实际更新的过程。
5. **衡光星系**：正则作用、排除替代解释、双故障与三故障。

Easy 提供直接引导；Medium 追查细节与特殊机制；Hard 组合多条证据。新手村的 Medium 仍保留引导，Hard 是温和的入门组合。

## 玩法

- 80 组真实训练结果，包括部分修复与完整修复。
- 每题 3 点生命；首次打开无关观测扣 1 点，重复查看不重复扣除。
- 每题一次解读；已解锁解读可以免费回看。
- 深层观测在查看对应前置后才出现；合理排除也算有效证据。
- 每题明确说明降低 loss 或缓解反弹的目标，完整修复 MSE 仅作实测参考；通关按 setup 调整是否正确判定。
- 通关后展示可迁移的直觉。本机保存进度，刷新后可继续；重开只重置当前题。

## 本地运行与部署

下载 `index.html` 后直接用浏览器打开，无需安装依赖。样式、脚本和数据内嵌，网页不现场训练模型。

这是静态发布仓库，GitHub Pages 从 `main` 根目录部署。更新 `index.html` 并推送后会自动重新部署。

实验采用固定随机种子的 NumPy MLP，是教学实例；新增题未经跨种子统计验证。完整修复仍允许出现波动，观测的有效性是当前题的教学标注。

关卡页顶部以当前星系名展开本章全部六颗行星，显示难度、答题状态和最近得分；地图与说明位于右侧。本关练习以顶部小字展示。星系与行星改名不改变关卡 ID，已有浏览器存档仍然有效。

## 拟合与观测复盘

每道题顶部提供免费的拟合小窗，对照目标函数与模型最终预测；提交后可以切换初始配置和最近一次实际执行的修复。未提交的设置草稿不会改变图像。

答卷的“观测复盘”默认收起，展开后可逐项查看所有有效与无关观测的修改前后曲线，包括未曾打开的深层指标。多分量观测分别绘图；不同训练预算保留真实步数。复盘不会消耗生命、提示或增加观测次数，历史答卷使用保存的提交结果。

星系选关保持在大地图中：飞船抵达后弹出紧凑窗口。卡片仅保留行星、难度、编号、状态、名称和简介；窗口内可独立滚动，标题与关闭按钮固定，适应后续增加题目。可点击关闭、空白遮罩或按 Escape 返回原地图位置。旧章节链接仍可使用，刷新后恢复对应弹窗。

星系与行星另有固定的虚构天文目录编号：星系 `SL-C01` 至 `SL-C05`，行星如 `SL-C03-P01 · 折岭之星`。SL 表示 Soup Lab，C 为星系，P 为行星；编号与中文名称并列展示，固定分配，不因显示顺序变化而重排，原有关卡链接与存档 ID 保持不变。

## 诊断模式与通关回看

“标准 / 挑战”位于题目难度旁。标准标出待调整项，挑战隐藏故障标记并开放完整配置作为候选。模式按关卡保存；切换不恢复生命和提示，不清空观测，切回标准只将未提交的正常项调整改回“保持”。历史答卷仍保留原提交结果。

通关后在观测室直接点击任意 observable，可同时查看修改前与通关后的曲线；未看过的指标和深层指标也开放免费复盘。回看不改动已结算的计数、生命、提示与得分，刷新后仍能恢复对比。未通关时依然只显示初始观测；Game over 不会因为切换模式而解除。
