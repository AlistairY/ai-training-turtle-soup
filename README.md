# Soup Lab · AI 训练海龟汤

[在线试玩](https://alistairy.github.io/ai-training-turtle-soup/) · [体验梯度传递关卡](https://alistairy.github.io/ai-training-turtle-soup/?case=08)

从真实的训练曲线和观测寻找故障，判断模型设置应该调高还是调低。

## 从新手村出发

30 道题分为 5 个大关，每关 6 题，Easy / Medium / Hard 各 2 题：

1. **新手村**：最初两题仅一个 observable 和一个错误 setup，逐步建立读图直觉。
2. **步长与训练预算**：单步进展、反弹、训练时间与组合限制。
3. **表达能力**：拟合形状、模型容量、有效活动与练习机会。
4. **梯度传递**：裁剪、饱和、梯度到实际更新的过程。
5. **约束与综合诊断**：正则作用、排除替代解释、双故障与三故障。

Easy 提供直接引导；Medium 追查细节与特殊机制；Hard 组合多条证据。新手村的 Medium 仍保留引导，Hard 是温和的入门组合。

## 地图选关

首页是深青与金色的「训练群岛」。左侧切换五个主题大关，中间点击六座关卡岛屿，右侧预览探索委托并进入调查。各大关分别以村落、风车、书库、晶石和观测台为场景。地图显示各区域和总通关进度，标记正在调查、已通关或需重试的关卡；可以随时返回地图继续调查，也能自由跳关。快捷列表支持按章节和难度筛选。

地图适配桌面与手机。`?view=map` 直接进入地图，`?case=08` 等旧链接仍直接进入对应题目；支持浏览器前进、后退。进度保留在当前页面内，刷新重置。

## 玩法

- 80 组真实训练结果，包括部分修复与完整修复。
- 每题 3 点生命；首次打开无关观测扣 1 点，重复查看不重复扣除。
- 每题一次解读；已解锁解读可以免费回看。
- 深层观测在查看对应前置后才出现；合理排除也算有效证据。
- 每题明确说明降低 loss 或缓解反弹的目标，完整修复 MSE 仅作实测参考；通关按 setup 调整是否正确判定。
- 通关后展示可迁移的直觉。切题保留本页内进度，刷新重置；重开只重置当前题。

## 本地运行与部署

下载 `index.html` 后直接用浏览器打开，无需安装依赖。样式、脚本和数据内嵌，网页不现场训练模型。

这是静态发布仓库，GitHub Pages 从 `main` 根目录部署。更新 `index.html` 并推送后会自动重新部署。

实验采用固定随机种子的 NumPy MLP，是教学实例；新增题未经跨种子统计验证。完整修复仍允许出现波动，观测的有效性是当前题的教学标注。
